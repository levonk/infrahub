## Summary

Create the Traefik dynamic config template for `files.levonk.com` routing to
the copyparty container, register it in the Traefik role tasks, and create the
`deploy-copyparty.yml` playbook that handles DNS + container deployment.

**IMPORTANT**: copyparty uses built-in basic auth, NOT Authelia. The Traefik
dynamic config must NOT include the `authelia` middleware.

## Sub-Tasks

- [ ] Create Traefik dynamic config template at
  `shared/active/02-config/ansible/roles/proxy-traefik/templates/dynamic/copyparty.yml.j2`:
  ```yaml
  # Traefik Dynamic Configuration - copyparty Routing
  # Generated by Ansible - DO NOT EDIT MANUALLY
  # Domain: {{ copyparty_domain }}
  # Security: copyparty built-in basic auth (NOT Authelia — copyparty handles auth internally)

  http:
    routers:
      copyparty-http:
        rule: "Host(`{{ copyparty_domain }}`)"
        entryPoints:
          - web
        middlewares:
          - redirect-to-https
        service: copyparty

      copyparty-https:
        rule: "Host(`{{ copyparty_domain }}`)"
        entryPoints:
          - websecure
        service: copyparty
        tls:
          certResolver: letsencrypt

    services:
      copyparty:
        loadBalancer:
          servers:
            - url: "http://{{ copyparty_container_name | default('copyparty') }}:{{ copyparty_container_port | default('3923') }}"
          passHostHeader: true
  ```
- [ ] Register the template in `shared/active/02-config/ansible/roles/proxy-traefik/tasks/main.yml`:
  ```yaml
  - name: Deploy copyparty dynamic configuration template
    ansible.builtin.template:
      src: dynamic/copyparty.yml.j2
      dest: "{{ proxy_traefik_data_dir }}/config/dynamic/copyparty.yml"
      owner: root
      group: root
      mode: "{{ infra_mode_file }}"
    become: true
    notify: reload traefik
    when: copyparty_enabled | default(false) | bool
    tags: ["deploy", "traefik", "copyparty"]
  ```
  **Placement**: Add this near the other service dynamic config deployments (e.g., near the n8n or rustfs entry). Read the file first to find the right insertion point.
- [ ] Create playbook `shared/active/02-config/ansible/playbooks/deploy-copyparty.yml`:
  - **Play 1**: Configure Cloudflare DNS (hosts: localhost, vars_files: shared domains.yml + client domains.yml + vault)
    - `cloudflare_dns_records` with one CNAME entry for `files.levonk.com` → `{{ ts_fqdn }}`
    - Role: `cloudflare-dns`
    - Tags: `["dns"]`
  - **Play 2**: Deploy copyparty + Traefik routing (hosts: cloud_servers, become: true)
    - `vars_files`: shared ports.yml, networks.yml, storage.yml, domains.yml + client domains.yml + vault
    - Roles: `storage-copyparty` (tags: `["deploy", "copyparty"]`)
    - Tasks: Deploy Traefik dynamic config template (same pattern as deploy-rustfs.yml Phase 2)
    - Handlers: `reload traefik`
  - Follow the pattern of `deploy-n8n.yml` (same-host OCI service with DNS + container + Traefik)
  - Add usage comments at the top (ansible-playbook command with vault password file)
